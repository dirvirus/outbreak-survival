# OUTBREAK — 2.5D зомби-выживание

Бесплатная браузерная выживалка **в одном HTML-файле**: без установки, без интернета, без зависимостей.

- 🎮 **Играть онлайн:** открой `outbreak.html` в браузере (или сайт `index.html`).
- ⬇ **Скачать:** `outbreak.html` (~347 КБ) и запустить двойным кликом.
- 📴 **Офлайн:** все текстуры, оружие и звук уже внутри файла.

## Что внутри

| | |
|---|---|
| Карты | **ПЕРЕУЛОК** (улица) и **АУТПОСТ ВЫЖИВШИХ** (укреплённый двор за стеной с воротами) |
| Герои | Курьер (пистолет + дробовик), Эмми (винтовка + пистолет), Ниндзя (катана + дым, 4 гранаты) |
| Транспорт | Пикап M998: давит мертвецов, турели (до 3) с перегревом, ремонт и прокачка в цехе «Гром» |
| Строительство | забор, турель, костёр — за доски и металл |
| Мертвецы | ходоки, бегуны, толстяки, бронированные, плевуны, «ночные» |
| Задания | линейная цепочка из 22 заданий (по 11 на карту) |
| Рекорд | лучший счёт хранится локально в браузере |

## Управление

`WASD` — движение/руль · `ЛКМ` — огонь · `1` `2` — оружие · `E` — сесть/выйти из пикапа ·
`U` — мастерская · `3` `4` `5` — забор/турель/костёр · `G` — граната/дым · `Пробел` — ручник · `Esc` — пауза.

## Особенности аутпоста

Двор занимает половину карты и обнесён бетонной стеной по периметру с вышками по углам.
Ворота разъезжаются только перед игроком и пикапом — **мертвецы снаружи и внутрь попасть не могут**,
а на самой территории они вообще не появляются.
